Primary call-to-action; Bebas Neue caps in a pill with a trailing ↗ arrow (`outline` is the signature "BOOK NOW").
```jsx
<Button variant="outline" tone="dark">Book now</Button>
<Button variant="bar" icon="arrow-right">Book Now</Button>
```
- `outline` inverts fill on hover. `solid` red. `bar` = full-width ticket button inside BookingCard (sentence case, Archivo).
